0.6 AUTHENTICATION / PERMISSION RULES
============================================================

Login
> User opens app
> User must authenticate
> Recommended login method
   > Google login
> After login
   > Match email to users table
   > Load user_access record
   > Load allowed halls
   > Load permissions
> If user not found
   > Show access denied
   > Message
      > Your account is not set up. Please contact admin.
> If user inactive
   > Block access
   > Message
      > Your account is disabled. Please contact admin.

Admin Rules
> Admin sees all pages
> Admin sees all halls
> Admin sees school and simcha events
> Admin can edit settings
> Admin can create/edit/delete events
> Admin can assign workers
> Admin can view payment info
> Admin can send payment emails

Hall Secretary Rules
> Can view calendar if allowed
> Can create booking if allowed
> Can view event manager if allowed
> Can edit events if allowed
> Can view assigned halls only unless allowed all
> Can send payment emails only if allowed
> Can view payment information only if allowed

Kitchen Admin Rules
> Can view kitchen dashboard
> Can assign workers
> Can update kitchen item statuses
> Can view simcha/school events depending permissions
> Cannot view payment totals unless specifically allowed

Kitchen Worker Rules
> Can view kitchen dashboard if allowed
> Can update item status if allowed
> Can only see assigned/allowed halls if restricted
> Cannot see payment totals
> Cannot edit event financials
> Cannot access settings unless explicitly allowed

School Manager Rules
> Can manage school cycles if allowed
> Can view kitchen dashboard if allowed
> Can see school events
> Can edit school schedule
> Cannot manage payment settings unless admin

Permission Enforcement
> Enforce permissions on frontend
> Enforce permissions again in API routes
> Never rely only on hidden buttons
> API must reject unauthorized actions
> Every protected API route checks current user
> Every event query filters by allowed halls and event category if needed

   > Save google_sync_error
   > Show toast
      > Google Calendar sync failed. The event was saved locally.
